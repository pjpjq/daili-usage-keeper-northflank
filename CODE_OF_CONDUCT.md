# Code of Conduct

## Our standard

We are committed to providing a welcoming, respectful, and harassment-free
community for everyone. Be constructive, assume good intent, and focus on the
work rather than the person.

Unacceptable behaviour includes harassment, discrimination, personal attacks,
unwelcome sexual attention, publishing private information, and any conduct
that would be inappropriate in a professional setting.

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, pull requests,
and other contributions that violate this Code of Conduct. Repeated or serious
violations may result in a temporary or permanent ban from project spaces.

Report a concern privately to the project maintainers through GitHub. Reports
will be handled confidentially where possible. Please include the relevant
links, dates, and any supporting context.

This Code of Conduct applies to all project spaces and to anyone representing
the project in public.
